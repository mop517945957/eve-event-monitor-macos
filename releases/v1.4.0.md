# EVE 事件监测 v1.4.0（macOS）

本次发布增加多角色窗口预览和本地预警频道监控。每个角色独立读取所在星系、计算预警距离，不需要 ESI 授权或联网查询位置。

## 新增功能

- **多窗口预览**：只列出 EVE 游戏角色窗口；无标题栏和底栏，可拖动位置、自由缩放、调节透明度，布局自动保存。点击预览切换到对应游戏窗口，支持跨桌面切换。
- **每角色独立设置**：可收起的窗口卡片中设置监控区域、宽高滑条与数值、透明度。区域在对应游戏窗口的快照中框选。
- **一键恢复监控**：开始全部监控会恢复已保存监控区域的在线角色，各窗口独立进行视觉检测。
- **本地频道黄色预警**：从游戏日志读取角色跳跃位置，从所选玩家预警频道提取危险报告；每个角色独立计算普通星门最短跳数。默认 3 跳内、报告有效期 5 分钟，均可调整。
- **离线星图**：内置 8,490 个星系与 6,989 条星门连接。应用运行时不调用官方位置接口、不上传聊天日志。
- **分级报警**：预警频道触发对应预览黄框与提示音；现有视觉识别发现危险时触发红色报警，红色优先。当前星系的频道报告也只触发黄色预警。
- **全局锁定快捷键**：可设置快捷键锁定预览、让鼠标点击穿透；报警自动解锁。锁定/解锁提示约 2.5 秒后隐藏。
- **刷新率选项**：预览支持 10、15、30、60 FPS，默认 30 FPS；实际效果受游戏后台帧率和系统性能影响。

## 修复与改进

- 修复预览流关闭时信号量释放引起的偶发崩溃。
- 改善跨桌面切换、窗口标题匹配、临时捕获中断恢复及窗口列表保持。
- 移除重复窗口选择入口和固定样式/图标识别设置。
- 本地日志支持 UTF-8/UTF-16、增量读取、分段写入、轮换及重复报告去重；忽略本地频道、置顶信息和状态询问。
- 同星系新危险报告刷新有效期；`clr / clear` 清除同频道对应报告。范围内无有效报告时解除黄色预警，视觉红色警报独立工作。

## 安装与使用

1. 下载 `EVE-Event-Monitor-macOS-arm64-v1.4.0.dmg`，打开后把 ScreenAlarm 拖入 Applications。
2. 需要 macOS 13 或更高版本，安装包适用于 Apple Silicon（M 系列）。此包为本地签名，未做 Apple 公证；首次打开可能需要在系统设置的隐私与安全性中允许打开。
3. 授予屏幕录制权限；跨窗口切换、全局交互及可选自动点击按提示授予辅助功能权限。
4. 展开角色卡片设置监控区域，在“预警频道”勾选频道、设置跳数和有效期，然后点击“开始全部监控”。默认日志目录为 `~/Documents/EVE/logs`，可自行选择。

## 验证与限制

- Release 编译、现有预览回归测试、本地日志与多角色距离计算测试通过；已用真实日志验证角色位置读取。
- 每 2 秒读取新增日志，不代表游戏写入延迟保证。实际多人游戏场景的黄色报警仍需继续验证。
- 初版按消息开头的完整星系名识别，不支持全部玩家缩写或任意自然语言。报告过期不等于星系安全。
- 跳数只计算普通星门，不包含玩家跳桥和动态虫洞；特殊移动是否都写入位置日志尚未验证。无匹配位置时显示未知，不借用其他角色的位置。
- 本次只更新 macOS；Windows 旧版本保留在历史 Release，不具备上述新增功能。
